# Power Zone Fitness Club

Student practical web development project (Semester 1, 2026-2027).
Built with HTML5, CSS3 (Flexbox) and vanilla JavaScript only.

## Folder structure

```
Business_Website_YourName/
├── index.html      Page structure (all 7 sections)
├── style.css       All styles (colors are CSS variables at the top)
├── script.js       Slider, program cards, form validation and extras
├── images/         Hero and gallery photos
└── evidence/       Empty - put your own test screenshots here
```

## How to run locally

1. Unzip the folder.
2. Rename `Business_Website_YourName` so it includes your name.
3. Double-click `index.html` to open it in Chrome, Edge or Firefox.

   Or, in VS Code, right-click `index.html` and choose "Open with Live Server".

No installation or internet connection is needed, except for the Google Fonts
(if offline, the page falls back to system fonts).

## Before submitting

- Replace `[Student Name]` in the footer of `index.html` with your name.
- Take your own screenshots and save them in `evidence/`.
